# ex-fetch

A simple example project demonstrating how to use the native Fetch API in a React + TypeScript application.

The app fetches users from a public API, displays them in a clean UI, and allows searching users by name.

---

## Features

* Fetch data using the native Fetch API
* Search users in real time
* Loading and error handling
* Copy email to clipboard
* Built with React + TypeScript
* Simple and beginner-friendly example

---

## Tech Stack

* React
* TypeScript
* Vite
* npm

---

## Getting Started

### Clone the repository

```bash
git clone https://github.com/r01d3/ex-fetch.git
cd ex-fetch
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```
---

## API Used

This project uses:

* JSONPlaceholder API
* [https://jsonplaceholder.typicode.com/users](https://jsonplaceholder.typicode.com/users)
